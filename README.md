# ML Notebooks

A hands-on machine learning learning journey — Jupyter notebooks covering the full ML workflow, from data wrangling to deep learning and GenAI.

## Topics Covered

- **Data Fundamentals** - NumPy, Pandas, statistics, data preprocessing
- **Supervised Learning** - Linear/Logistic Regression, KNN, SVM, Decision Trees, Random Forests
- **Unsupervised Learning** - K-Means clustering, PCA
- **NLP** - Text processing, SMS spam classification
- **Deep Learning** - CNNs, Keras, neural networks, TensorFlow
- **Applied Projects** - Next-word prediction, real-time emotion detection
- **GenAI** - Agentic AI concepts

## Structure

Notebooks are organized by learning progression. Each topic pairs with its relevant CSV datasets included alongside.
